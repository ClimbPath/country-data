# ClimbPath Country Data
A structured JSON dataset of countries for geographic applications and search systems.

## Contents
Each country includes:

- ISO 3166 country codes
- English and native names
- Geographic coordinates and bounding boxes
- Search aliases for multilingual discovery
- Languages, time zones, and capital cities

## Usage
The dataset can be used in applications, maps, search systems, and other geographic projects.
